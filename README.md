# CS2 自动剪辑

拖入一场 CS2 Demo，选个选手，就能一键导出他的高光、击杀或死亡合集；打开「击杀-死亡」统计，1 杀 20 死会自动显示为 **`i20`**。

工具在 Windows 本地解析 Demo、录制选手视角并生成 MP4。[下载源码 ZIP](https://github.com/Erbsen16/cs2-demo-clipper/archive/refs/heads/main.zip) · [GitHub 项目主页](https://github.com/Erbsen16/cs2-demo-clipper)

## 启动

1. 在 Windows 10/11 x64 上安装 Python 3.11–3.13（勾选 **Add python.exe to PATH**）、Steam 和 CS2。
2. 在 GitHub 点击 **Code → Download ZIP** 并解压，或使用 Git 克隆仓库。
3. 双击解压目录里的 **Start CS2 Editor.cmd**。首次启动会安装 Python 依赖，从上游发布页下载录制组件并验证 SHA-256。准备完成后会自动打开本地网页。使用期间保留启动窗口。

如需剪辑已有录像，完成首次启动后可运行 `python app.py` 打开桌面界面。

## 直接从 Demo 自动出片

保持 Steam 登录，先退出正在运行的 CS2，再在本地网页中操作。

1. 拖入比赛的 `.dem` 文件，从名单里选一名选手。
2. 选择 **高光**、**全部击杀**、**全部死亡** 或 **击杀和死亡**。要做狙击、步枪、手枪或冲锋枪合集，可在「枪械」里筛选。
3. 点 **自动导出 MP4**。工具会启动 CS2 录制，完成后浏览器会下载成片。

想剪出 fEAR 的 `i20` 第一视角？在对应的 Inferno Demo 里选 **fearcs2**，剪辑模式选 **击杀和死亡**，画面统计选 **击杀-死亡**，再取消 **显示 KILLS 字样**。片中战绩会随比赛更新，到第 20 次死亡时显示为 `i20`。

网页使用首次启动时下载的 [CS2 Video Generator](https://github.com/CS2OpenDev/CS2VideoGenerator/releases/tag/v0.10.1) 驱动本机 CS2 录制，再用 FFmpeg 烧录击杀计数并合并。默认 1280×720、24 帧。录制组件会临时备份和调整游戏文件并在录制结束后还原，请等待结束再进行在线游戏。

## 高光与单回合特剪

高光可勾选多杀、爆头、盲狙、穿烟和穿墙，满足任一勾选条件就会入选。单回合特剪先按同样的条件列出可选回合，再剪出所选回合内该选手的击杀。特剪保留击杀前 3 秒和后 1.5 秒，合并连续交火，用画面和声音的短淡入淡出衔接分开的片段。

## 高级设置

网页的「导出视频」区域有一个默认关闭的 **高级设置** 开关。开启后可按 16:9、4:3 或 16:10 选择实际录制分辨率，并调整帧率、编码画质、观察视角和第一人称持枪视野。雷达面板大小和地图缩放分别对应 CS2 的 `cl_hud_radar_scale` 与 `cl_radar_scale`。高级模式采用固定雷达缩放。

第一人称参考图以 Inferno 实录画面为背景。可单独调节战绩字号。左侧参考图显示基准构图，右侧随参数调整实时更新。可让战绩跟随示意雷达下缘，也可点击或拖动右图自定义位置。参考图为布局示意，实际地图、HUD 安全区、游戏光影及压缩效果以成片为准。关闭开关会使用普通模式的录制参数。

## 画面统计

导出时可选「仅击杀」「击杀-死亡」或「不显示」，也可以单独取消「显示 KILLS 字样」以只保留数字。「仅击杀」累计成片里出现的击杀。「击杀-死亡」按比赛时间显示选手的全场累计战绩，即使只剪某类枪械也会带入片段开始前的战绩。击杀数恰好为 1 时使用小写 i，例如 0-3 → i3 → i4 → 2-4，1 杀 20 死显示为 i20。

## 从已有录像剪辑

1. 选择 CS2 比赛的 `.dem` 文件，再选择选手。
2. 选择同一场比赛中该选手的连续视角录像。用 CS2 回放 Demo，切到该选手，以正常速度录制并避免暂停、跳转或切换视角。
3. 在事件表中选中一条击杀或死亡，点击 **用选中事件对齐** 自动填入 Tick，再输入同一事件在录像中的秒数。例如，界面显示首个击杀在 Tick 6400，录像里看到该击杀发生在 12.5 秒，就填 Tick 6400 和录像 12.5 秒。Tick 率默认 64。
4. 选择 **高光**、**全部击杀**、**全部死亡** 或 **击杀和死亡**。击杀和高光可以按狙击、步枪、手枪、冲锋枪筛选。
5. 选好画面统计样式，点 **从已有录像导出**。

高光规则包括单回合多杀、爆头、盲狙、穿烟和穿墙。每个事件截取前 5 秒至后 3 秒，重叠片段合并。
